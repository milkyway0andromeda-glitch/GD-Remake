# Web Dashers — Electroman Adventures Era

This build is intentionally capped at **Geometry Dash Update 1.6 / Electroman Adventures**.

## Kept
- Main levels 1–13, ending with Electroman Adventures.
- Cube, Ship, Ball, and UFO gameplay.
- Gravity, mirror, and size portals used by the 1.6-era levels.
- Jump pads/rings, secret coins, destructible/invisible blocks, decorations, and the historical editor object set.
- The existing Web Dashers editor and online/API infrastructure, where it does not require later gameplay objects.

## Removed / blocked
- Main levels after Electroman Adventures.
- Later level/music/background/ground content.
- Object IDs after 197 (the first post-cutoff level data uses IDs above this).
- 1.7+ speed/speed-era objects.
- 1.8 dual/slope-era objects.
- 1.9 wave-era objects and standalone wave assets.
- 2.x robot/spider/teleport and other later object mappings.
- Later robot/spider/wave icon tabs from the icon selector.
- Later standalone particle/pixel/robot/spider/wave asset files.

Imported or online levels containing post-cutoff object IDs have those objects ignored instead of allowing later gameplay features back into this build.
